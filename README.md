# Jeu du Pendu - C#

Petit jeu du pendu réalisé en C# en application console.

Projet réalisé dans le cadre d’un exercice de programmation.

## Fonctionnalités
- Saisie des lettres par le joueur
- Vérification des bonnes/mauvaises réponses
- Affichage progressif du mot
- Gestion des erreurs restantes
- Affichage dynamique dans la console

## Concepts utilisés
- Boucles
- Conditions
- Fonctions
- Gestion de l’affichage console

## Technologies
- Langage : C#
- Framework : .NET 10
- Type : Application Console
- IDE : Rider

## Améliorations possibles
- Ajouter plusieurs niveaux de difficulté
- Ajouter une liste de mots aléatoires
- Ajouter des couleurs dans la console
- Ajouter un mode multijoueur
- Sauvegarder les scores
